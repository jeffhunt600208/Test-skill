# 配色系统(Color System)

整套配色由 `:root` 里 **6 个 token** 驱动。换色 = 改这 6 个变量,不要逐处改颜色。

```css
:root{
  --ink:#14110d;        /* 主深色:深色页背景 / 正文文字 */
  --paper:#f1ebdf;      /* 纸张底:浅色页背景 */
  --accent:#bf2118;     /* 主强调色:刊眉编号、kicker、标题高亮、满版强调页 */
  --accent-lt:#ff7a6e;  /* 浅强调色:深色背景上的高亮(必须在深底上清晰可读) */
  --accent2:#1d3a5c;    /* 对照色:仅用于 A/B 双色对比版面,不要当第二主色用 */
  --gold:#a9802b;       /* 点缀金:三栏对比的第三色 / 小装饰 */
}
```

## 三条铁律(踩过坑总结)

1. **主色只有一个。** `--accent` 是主角,贯穿刊眉、kicker、标题高亮、满版强调页、表格关键值。
   `--accent2` 只在"FAA vs EASA""实 vs 虚"这种 **A/B 双色对比**版面出现,别让它变成第二主色,否则版面会"花"。

2. **深色背景上绝不用主色当文字。** `--accent` 通常是深色(深红/深蓝/墨绿),放在 `--ink` 深底上几乎看不见。
   深底上的所有高亮(封面的强调词、深底数据页的大数字、机制链的强调、封底的 `<em>`)一律用 **`--accent-lt`**。
   换主色时,务必同步把 `--accent-lt` 调成同色系的**浅亮版**。

3. **对比版面要"底色 + 边 + 标签"同色系。** 双栏/双框对比里,一侧用主色系(淡底 + 主色边 + 主色标签),
   另一侧用对照色系。别出现"蓝底配红边"这种错配。第 6/8 类版面尤其注意。

## 即取即用调色板

把下面任意一组粘进 `:root` 覆盖前 5 个变量即可。

| 风格 | --ink | --paper | --accent | --accent-lt | --accent2 |
|---|---|---|---|---|---|
| **经典编辑红**(默认) | `#14110d` | `#f1ebdf` | `#bf2118` | `#ff7a6e` | `#1d3a5c` |
| **深航蓝** | `#11140f` | `#eef0e9` | `#1b3a63` | `#7fb0e0` | `#bf2118` |
| **森绿** | `#10130f` | `#eef0e6` | `#1f5132` | `#74c79a` | `#a9802b` |
| **墨黑金**(高端) | `#121212` | `#f0ece3` | `#9a7324` | `#e7c477` | `#5a5a5a` |
| **酒红** | `#15110f` | `#f1eae2` | `#7a2233` | `#e08097` | `#2a3b30` |

> 换主色记得一起换 `--accent-lt`(同色系浅亮版)与 `--paper`(冷主色配偏冷的纸,暖主色配偏暖的纸,更协调)。
> 默认纸张偏暖;深蓝/森绿这类冷主色建议把 `--paper` 调得更冷(如 `#eef0e9`)。

## 字体 token

```css
--serif:"Noto Serif SC","Playfair Display",Georgia,serif;   /* 衬线正文 / CJK 标题 */
--sans:"Noto Sans SC","Archivo",-apple-system,sans-serif;    /* 无衬线正文 / 标签 */
--display:"Playfair Display","Noto Serif SC",serif;          /* 大标题:拉丁用 Playfair,CJK 回落衬线 */
```

杂志感的关键:**大号 Playfair 衬线标题 + 无衬线小标签**的反差。导出 PDF 时本地没有 Playfair,
`export_pdf.py` 会把这些变量重映射到本地 Noto 字体(见该脚本注释)。
